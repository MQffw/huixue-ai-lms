## 约定

1. **新增文档先想归哪个目录**：接口类进 `api/`，环境/部署进 `env/`，评估类进 `analysis/`，AI 进 `ai/`。
2. **被取代的文档不要删，移到对应 `archive/`**，并在本索引标注"历史"。
3. **改完文档顺手核对相对链接**——文档层级变化后 `../` 数量会变，别留下 404。
4. **同一事实只写一处**：路径、端口、启动命令以根 [`README.md`](../README.md) 与 `env/本地Docker开发环境.md` 为准，
   其他文档引用即可，不要复制一份新的（复制出去的那份必然先过期）。
5. 根目录 `CLAUDE.md` 是 AI 编程助手的约定文件，**必须留在根目录**，移到子目录会失效。

## 目录之外

| 路径 | 说明 | 是否入库 |
|---|---|---|
