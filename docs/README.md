## 目录说明

| 路径 | 用途 | 是否入库 |
|---|---|---|
| `src/`、`frontend/` | 源码 | 是 |
| `config/models.json` | 模型注册表（含加密 Key） | 否 |
| `deploy/` | nginx 反代 `default.conf`、库初始化 SQL（`mysql-init/`）、Maven 镜像配置（`maven/`）、本机 MySQL 8 实例模板（`mysql80/`） | 是 |
| `scripts/` | 只放 Docker 启停：`dev-up.bat` / `dev-down.bat` | 是 |
| `uploads/` | 知识库原始文件（数据库里有引用，**勿删**） | 否 |
| `target/`、`logs/`、`frontend/dist/` | 构建与运行产物，可随时删 | 否 |

## 清理约定

- 构建产物、日志、`frontend/dist` 随时可删，重新构建会生成；
- `uploads/` 里只保留数据库 `hxt_knowledge_doc.file_path` 引用到的文件，其余是失败重传的残留，可删；
- Maven 依赖统一走用户目录 `~/.m2`，**项目内不再保留 `.m2repo` 与 `.mvn/maven.config`**（2026-11 清理）；
- 数据库备份（5.5 整库 / tlias / 迁移 dump）与 Apifox 导出资产已移出仓库，存放在 `IdeaProjects/_hxt-archive/2026-11-13/`。
