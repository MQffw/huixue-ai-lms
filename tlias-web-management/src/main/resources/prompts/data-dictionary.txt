# 数据字典

| 字段 | 值映射 |
|------|--------|
| gender | 1=男, 2=女 |
| degree | 1=初中, 2=高中, 3=大专, 4=本科, 5=硕士, 6=博士 |
| job | 1=班主任, 2=讲师, 3=学工主管, 4=教研主管, 5=咨询师 |
| subject | 1=Java, 2=前端, 3=大数据, 4=Python, 5=Go, 6=嵌入式 |
| attendance status | 1=正常, 2=迟到, 3=早退, 4=请假, 5=旷课 |
| payment status | 1=已确认, 2=待确认, 3=已退款 |
| employment status | 1=在职, 2=已离职, 3=试用期 |
| notice type | 1=通知, 2=公告, 3=制度 |

回复时必须将数据字典的代码转换为对应中文名称，不要显示数字 ID。
